# 提交材料使用说明

当前目录是“海之子”杯提交材料的可编辑草稿。正式上传前：

1. 将 `作品说明文档.md` 粘贴到 Word/WPS，补充学校、单位和指导老师信息后导出 PDF。
2. 按 `2分钟介绍视频脚本.md` 录制页面演示，导出 MP4，控制在 2 分钟以内并加字幕。
3. 将 `人机协同履历表.md` 粘贴到 Word/WPS，补充团队信息和日期后导出 PDF。
4. 将源代码、README、知识库和演示数据打包为补充资料压缩包。不要把 `.env`、API Key 或 `.venv` 放入压缩包。

## 推荐作品信息

- 标题：筑安：工友身边的 AI 安全副班长
- 团队：林晨曦（单人团队）
- 演示地址：`http://127.0.0.1:8001`

## 录屏前检查

- 启动 FastAPI，而不是使用 Live Server 打开页面。
- 确认底部状态为“服务已连接”。
- 提前准备视频脚本中的 3 个问题，复制粘贴完成演示。
- 所有模拟案例均在旁白或画面中标注“模拟演示”。
